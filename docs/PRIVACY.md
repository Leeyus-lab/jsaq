# 数据与隐私说明（PRIVACY）

本页面如实说明软件运行过程中所有涉及网络传输的数据。

## 一、会外发的数据（共两类）

### 1. 用量统计（匿名，可关闭）

任务完成时，软件会向上游项目作者维护的统计服务器发送一次匿名统计：

- **目标**：`http://101.133.233.225:81/result_update`（上游 jiangsu-safety-platform-skip 项目的统计服务）
- **内容**：仅两项 ——
  ```json
  { "score": 100, "runtime_ms": 45230 }
  ```
  即本次考试得分与运行耗时（毫秒）。
- **绝不包含**：账号、密码、姓名、学校、班级、userId、IP 归属、设备信息、浏览器指纹等任何可识别个人身份的内容。
- **代码位置**：`app.py` 的 `upload_stats()`（桌面端）与 `webui/app.js` 的 `uploadStats()`（安卓/网页端）。
- **如何关闭**：删除上述两处函数调用即可，不影响任何功能。

### 2. 公益接口请求（仅配置 Token 后）

若你在 `bbhj.js` 中配置了起零数据 Token，软件启动时会请求：

- **目标**：`https://api.istero.com/resource/v1/baby/come/home?token=<你的Token>`
- **性质**：只读拉取走失儿童公益信息，不提交任何本机数据；
- Token 仅保存在本地文件中，不会发送到本软件作者或任何第三方（除 API 服务方本身）。

## 二、仅保存在本机的数据

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 界面设置（主题/语言等） | 浏览器 localStorage；exe 端同步到 `%APPDATA%\jsaq_v21\state.json` | 纯本地 |
| 公益浏览记录 | 同上 | 纯本地，关闭软件后保留 |
| 输入的学校/账号/密码 | 仅内存中使用，**不落盘** | 关闭软件即消失 |

## 三、与平台的交互

软件需要与校园安全通平台（`xiaoyuananquantong.com`）通信以完成登录、课程与考试——这是工具的核心功能，等同于你手动使用该平台网页。你输入的账号密码仅用于向该平台本身登录，不经手任何其他服务器。
