如何获取链接 / userId？

获取链接：在微信里打开安全教育平台并登录，点击页面右上角"…"，选择"复制链接"。链接里 userid= 后面那串数字就是 User ID。

例如：...userid=2081342242378772482...
→ User ID = 2081342242378772482
